# Dossier Vidéos

Ce dossier contient les vidéos utilisées sur le site web.

## Structure recommandée :
- `objectif-video.mp4` - Vidéo principale expliquant les objectifs (max 1 minute)
- `objectif-video.webm` - Version WebM pour une meilleure compatibilité
- `video-thumbnail.jpg` - Image de miniature pour la vidéo

## Formats supportés :
- MP4 (recommandé)
- WebM (alternative)
- Taille maximale recommandée : 10-15 MB pour une vidéo d'1 minute

## Optimisation :
Pour optimiser vos vidéos, vous pouvez utiliser :
- Résolution : 1280x720 (720p) ou 1920x1080 (1080p)
- Bitrate : 1000-2000 kbps pour une bonne qualité
- Format : H.264 pour MP4
